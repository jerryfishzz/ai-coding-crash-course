Repo field guide

Schema change → migration → behavior

app/db/schema.ts → npm run db:generate → review drizzle/*.sql → npm run db:migrate → update and verify app behavior
  1. Change the Drizzle TypeScript schema to describe the intended database shape.
  2. Generate a versioned SQL migration. Generation does not apply it.
  3. Review the SQL, especially table rebuilds, foreign keys, defaults, and existing data.
  4. Apply it to the configured database with npm run db:migrate.
  5. Update services, validation, and UI. A schema change alone is not a complete feature.

In this repo drizzle.config.ts points to app/db/schema.ts, drizzle/, and data.db. Use a disposable database when experimenting with potentially destructive changes.

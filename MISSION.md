# Mission

Become an effective contributor to this full-stack course platform by learning how its request flow, domain services, and persistence fit together. Build on seven years of software development experience across React/JavaScript, React Native, and Flutter, while getting comfortable with this repository's TypeScript and server-rendered React architecture.

## Learning direction

Start by tracing one user-facing feature from URL to database and back. Then explore mutations, authorization, tests, and the repository's AI-assisted engineering workflow as they become relevant.

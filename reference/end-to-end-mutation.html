Repo field guide

Trace a mutation end to end

UI intent + fields → route identity/permission/validation → service operation → database state → loader revalidation → UI
  1. Find the UI handler and the exact submitted fields/intent.
  2. Find the route module and action selected by the request.
  3. Trace authentication, role, object ownership, nested-resource checks, and validation.
  4. Follow the service call to its Drizzle query and table.
  5. Check the response path and how the UI reflects the changed data.
  6. Choose tests at the boundaries: service contract, route authorization, UI interaction as needed.

Repo field guide

Follow a database write

UI submit → route action → authorize → parse and validate → domain service → Drizzle query → SQLite constraint/table → action response → refreshed UI
  • UI: gathers values and submits; it does not decide whether the caller is authorized.
  • Route action: reads the request, checks identity/role, validates input, and selects the operation.
  • Service: owns reusable domain rules and database operations.
  • Schema: declares tables, columns, and constraints in TypeScript; migrations record structural changes.
  • Database: persists rows and enforces constraints such as unique keys and foreign keys.

Row vs schema: an insert adds data to an existing table. A migration changes database structure or constraints.

Example: category route → category service → schema.

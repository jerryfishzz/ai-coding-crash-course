## Provisional assessment

Treat the learner as an experienced software developer with frontend strengths, not as a programming beginner. Refresh React and focus on React Router's server route model. Treat Express and SQL as useful foundations, then build confidence in domain services, relational modeling, Drizzle queries, validation/authorization, and migrations. Drizzle and this repository's patterns are new. This profile is self-reported and should be refined after a code-tracing exercise.

## Durable teaching decisions

- Use real route and service files rather than generic sample apps.
- Connect React Router actions/loaders to familiar request-handler and component mental models.
- Introduce database concepts incrementally: relationships and constraints, queries and joins, then migrations and transactions.
- Ask the learner to explain a code path; calibrate difficulty from their reasoning rather than years of experience.
- React Router is used here; Next.js is not part of this repository's stack.

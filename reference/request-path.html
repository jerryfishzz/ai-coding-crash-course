Repo field guide

Follow a request

URL → route table → route loader → service → Drizzle / SQLite → loader data → React component
  • Route config maps a URL pattern to a module.
  • Loader gathers request-specific data on the server.
  • Service owns reusable domain queries and writes.
  • Schema describes persisted tables and relationships.
  • Component renders the data; it need not issue the database query.

Useful example: course detail route.

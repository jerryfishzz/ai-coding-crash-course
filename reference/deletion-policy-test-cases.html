Repo field guide

Deletion policy test matrix

Start with a module that has a lesson, progress, quiz attempt, and watch event. Query the isolated test database after the operation.

RESTRICT: error + module/lesson/history remain
ARCHIVE: module archived + history remains + listing filters verified
CASCADE: intended descendants gone + unrelated rows remain
  1. Test the externally visible contract, not just an implementation detail.
  2. Assert important state after both success and failure.
  3. Include a nearby unrelated record to guard against overbroad deletes.
  4. For archive, test write behavior and normal/admin read behavior separately.
  5. For cascade, verify all intended FK descendants and ensure no undeclared relationship remains blocking deletion.

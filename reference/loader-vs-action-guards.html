Repo field guide

Guard writes in the action

Loader: prepare/guard page data
Action: authenticate + validate + enforce write invariants + mutate
  1. List each business rule enforced by the loader.
  2. Ask whether the action independently enforces every rule that must hold before a mutation.
  3. Remember that a direct POST need not follow a prior page load.
  4. Test the action directly with valid session/form data and a disallowed resource state.
  5. Assert the denial response and that no database rows were inserted or changed.

Repo example: purchase route. Check whether the current implementation matches the product requirement before changing it.

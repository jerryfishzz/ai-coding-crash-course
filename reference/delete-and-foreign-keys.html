Delete rules and foreign keys

Service rule → friendly domain error
Foreign key → database integrity guard
ON DELETE CASCADE → delete dependents automatically
ON DELETE NO ACTION → reject parent delete while dependents exist

Category example: categories is the parent; courses.categoryId is the child reference.

  • Service counts dependent courses and throws a readable error.
  • Schema declares the foreign key.
  • Connection enables SQLite FK enforcement.
